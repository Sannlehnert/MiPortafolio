Este es mi **portafolio personal** desarrollado con **React + Vite**, donde presento mis habilidades, proyectos y experiencia como desarrollador Full Stack en formación.  
El objetivo es tener un sitio profesional, rápido y responsive que pueda compartir con empresas y reclutadores.

---

## 🚀 Funcionalidades principales

- ✨ Interfaz moderna y minimalista.  
- 📂 Sección **Proyectos** para mostrar mis trabajos destacados.  
- 👨‍💻 Sección **Sobre mí** con mi perfil profesional.  
- 📱 **Responsive Design** (optimizado para PC y móviles).  
- ⚡ Cargado de manera ultra rápida gracias a Vite.  

---

## 🛠️ Tecnologías utilizadas

- **Frontend:** React + Vite  
- **Estilos:** CSS3 (con diseño responsive)  
- **Control de versiones:** Git y GitHub  
- **Deploy:** GitHub Pages / Vercel / Netlify (dependiendo de tu elección)
